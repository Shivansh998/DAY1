# DevOps Life Cycle – Tools and Their Uses

## 1. Plan – Jira, Azure Boards

Planning is the first step of the DevOps life cycle. In this step, the team decides what work needs to be done and divides it into tasks. Jira and Azure Boards help assign tasks to team members, track progress, and manage bugs.

## 2. Code – Git, GitHub

In this step, developers write the code for the application. Git is used to track changes in the code and maintain its history. GitHub is an online platform where developers store their code and work together on the same project.

## 3. Build – Maven, Gradle

After writing the code, we need to build the application. Maven and Gradle help compile the code, manage required libraries, and prepare the application for testing. They are commonly used in Java projects.

## 4. Test – JUnit, Selenium

Testing is done to check whether the application is working properly or not. JUnit is used to test individual parts of Java code. Selenium is used to automate website testing by performing actions like clicking buttons and entering data in a browser.

## 5. Release – Jenkins, GitHub Actions

After testing, the application is prepared for release. Jenkins and GitHub Actions help automate tasks such as building the code and running tests. They reduce manual work and help the team prepare software for deployment.

## 6. Deploy – Docker, Kubernetes

Deployment means making the application available for users. Docker packages the application and its required files into containers so that it can run in different environments. Kubernetes helps manage these containers and can scale applications when more resources are needed.

## 7. Operate – Ansible

The operate stage involves managing the application and the servers where it runs. Ansible is used to automate tasks such as server configuration and software installation. It saves time and reduces repeated manual work.

## 8. Monitor – Grafana

After deployment, we need to check whether the application is running properly. Grafana displays information such as CPU usage, memory usage, and application performance through dashboards. It helps the team identify problems and take action.

## Conclusion

All these tools are used at different stages of the DevOps life cycle. They help the team plan work, manage code, build and test applications, deploy software, and monitor its performance. DevOps makes software delivery faster and reduces manual work.
